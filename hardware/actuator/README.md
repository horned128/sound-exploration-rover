# アクチュエータ

Sound Exploration Roverで使用する購入アクチュエータの記録です。購入したバリエーションを最優先の情報とし、販売ページに掲載された一般仕様や計算値は個別仕様書で区別します。

ホイールはD軸へ樹脂リムを直接取り付ける `rim.stl` ではなく、[12 mm真鍮六角ハブの選定・取付手順](docs/jga25-wheel-hub-adapter.md)に従って `rim_hexagonal.stl` を使用します。

## 情報の扱い

個別仕様書では、情報を次の順で扱います。

1. 購入時に選択したバリエーション
2. 対象販売ページに記載された仕様
3. 販売画像やシリーズ共通表から読み取った参考値
4. 計算による推定値

実機測定値を追加する場合は、測定日、条件、使用機器を併記します。販売ページと実測値が異なる場合は、実測値を設計基準として採用します。

## 共通の設計注意事項

- 12 Vモーター電源、サーボ電源、マイコン電源を混同しない
- モーターとサーボをマイコン基板の小電流電源端子から直接駆動しない
- 信号を接続する機器間ではGNDを共通化する
- 初回試験は無負荷かつ電流制限付きで行う
- ストール電流、逆起電力、ブラシノイズを考慮してドライバと電源を選定する
- 可動端、回転方向、配線色、エンコーダ分解能は実機で確認する

EK-RA8P1への具体的な接続先とCPU0/CPU1のサンプル実装は、[EK-RA8P1 アクチュエータ制御サンプル](../../firmware/ra8p1/README.md)にまとめています。
