## 1. 製品概要

DS3225MGは、フルメタルギアとCNC加工アルミニウム製ミドルケースを採用した、高トルク型デジタルサーボです。

RCカー、クローラートラック、ロボットアーム、ボート、各種ロボット機構などの位置制御用途に使用できます。

販売ページの商品名と購入時の選択仕様はいずれも180°です。安全に使用できる実際のPWM可動端は、リンク機構を外した状態で実機確認してください。

## 4. 電気仕様

| 項目 | 5.0 V動作時 | 6.8 V動作時 |
|---|---:|---:|
| アイドル電流 | 約4 mA | 約5 mA |
| 無負荷動作速度 | 0.16秒/60° | 0.14秒/60° |
| ストールトルク | 約24.5 kgf·cm | 約28 kgf·cm |
| ストール電流 | 約2.1 A | 約2.9 A |

### 電源設計上の注意

- サーボ電源は、制御基板の小電流用5 V端子から直接供給しないでください。
- 起動時、急加速時、負荷変動時には大きな瞬間電流が流れます。
- 6.8 Vで使用する場合、少なくとも3 A以上を安定供給できる電源を推奨します。
- 複数台を同時駆動する場合は、同時ストール電流を基準に電源容量を見積もってください。
- マイコンとサーボ電源を分離する場合でも、GNDは共通化してください。
- 電圧降下やマイコンのリセットを防ぐため、サーボ電源付近に電解コンデンサを配置することを推奨します。

## 5. PWM制御仕様

| 項目 | 仕様 |
|---|---|
| 制御信号 | PWM |
| パルス幅範囲 | 約500～2500 µs |
| ニュートラル位置 | 約1500 µs |
| 動作周波数 | 50～330 Hz |
| デッドバンド幅 | 約3 µs |
| 信号電圧 | 3.3～5 V系ロジックを想定 |
| 回転方向 | パルス幅増加時に反時計回りとされる仕様 |

### 購入した180°モデルについて

180°モデルでは、一般的に500～2500 µsの入力範囲が約180°の機械角に割り当てられます。ただし、個体や販売仕様によって安全に使用できるパルス幅範囲が異なる場合があります。

初回動作時は、1500 µsを中心として、次のように徐々に範囲を広げてください。

1. 1500 µsでニュートラル位置を確認する。
2. 1000～2000 µs程度の狭い範囲から試す。
3. 異音、振動、発熱、機械端への衝突がないことを確認する。
4. 必要な範囲だけ段階的に500～2500 µsへ拡張する。

機械端を超えて指令すると、サーボがストールし、大電流、発熱、ギア損傷の原因になります。

## 9. 防水・使用環境上の注意

販売情報ではIP66相当と記載されていますが、水中使用には対応していません。

- 軽い水滴や飛沫への耐性を想定した仕様です。
- 水中へ沈めないでください。
- ケーブル出口、出力軸、ケース接合部から浸水する可能性があります。
- 結露、塩水、泥水、薬品が付着する環境では追加の防水処理が必要です。
- 防水性能は使用状態、経年劣化、分解歴によって低下します。

---

## 10. 取扱上の注意

- 動作電圧範囲を超える電圧を印加しないでください。
- 出力軸を手で無理に回さないでください。
- 長時間のストール状態を避けてください。
- サーボホーンとリンク機構が機械端に衝突しないように設計してください。
- 高負荷用途では、出力軸へ横荷重が集中しないよう外部軸受を検討してください。
- 電源配線はストール電流に耐えられる太さにしてください。
- マイコンのPWM信号を接続する前に、電源極性を確認してください。
- 初回試験は無負荷または低負荷で実施してください。
- 発熱、異音、振動、応答不良が発生した場合は直ちに電源を切ってください。

## 11. 仕様上の留意点

販売情報には、次の不整合または曖昧な表記があります。

### 11.1 制御角度

本書では購入仕様に従い180°として扱います。シリーズ内の別角度モデルや販売画像の共通表記は、購入品の仕様判定には使用しません。

### 11.2 トルク表記

商品名では25 kgf·cm級ですが、電気仕様では次の値が示されています。

- 5.0 V時：約24.5 kgf·cm
- 6.8 V時：約28 kgf·cm

25 kgは製品クラスまたは代表値と考えられます。

### 11.3 防水表記

説明文には「防水サーボ」と「防水サーボではない」という相反する記述があります。実用上は「防滴・耐水性能はあるが、水中使用不可」と解釈してください。

### 11.4 パルス幅の単位

販売文中の「500～2500秒」は誤記です。正しくは「500～2500マイクロ秒（µs）」です。

### 11.5 回転方向

回転方向は、サーボを観察する向きやホーンの取付方向によって見え方が変わります。実機で確認してください。

## 13. 参考換算

トルクの概算換算は次のとおりです。

```text
1 kgf·cm ≒ 0.0981 N·m
24.5 kgf·cm ≒ 2.40 N·m
25.0 kgf·cm ≒ 2.45 N·m
28.0 kgf·cm ≒ 2.75 N·m
```

これらはストール時の最大値です。連続運転で同等のトルクを維持できることを意味しません。実設計では、必要トルクに対して十分な安全率を確保してください。
